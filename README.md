# Smart Lab Safety

AI-Powered Smart Laboratory Safety and Knowledge Assistant.

## Project Structure

- `backend/` — Python backend and API routes
- `src/` — React frontend
- `dataset/` — Dataset configuration and validation
- `tests/` — Project tests

## Frontend Setup

Install dependencies:

```bash
npm install
```

Start the frontend using the script configured in `package.json`.

## Backend Setup

Install the Python dependencies listed in `backend/requirements.txt`, if that file exists.

## Features

- Laboratory safety monitoring
- PPE detection interface
- Safety procedures and knowledge assistant
- Sensor monitoring and alerts
